Why the number is a floor, not a total

The count moves because it is real: MangaDex publishes a total per original language, so ticking Manhwa genuinely adds its 8,809 Korean titles — 75,579 Japanese, 6,378 Chinese, 94,626 all told, each read off its API. Every other source pages without ever saying how deep it goes; Weeb Central still returns results on page 60. Hence the +: a floor, because a grand total would have to be invented.

Working, or not working

No milliseconds. A source is fine, or it is not reachable, and only the second is worth interrupting you about. Comick gets a third state — it finds titles and serves no chapters by design, which is exactly what made it look broken before.

Skippable, then not

A reader is one tap, not a blank field \u2014 a name and a colour bundled, because on a first run they are one decision. Typing your own is there, one card along, rather than being the default. The whole step is skippable and says so. Sources are not: Continue stays dim until one is on, because an empty home page is what this flow exists to prevent.

Only once

Shown when there is no library, no reading history and no sync code — an unambiguous new install. Everyone else lands on Home and reaches the same screens from Settings → Sources, which is Option A: seven groups down to four.
