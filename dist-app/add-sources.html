What is Source Fabric doing?
Known executable sources are connected immediately. For ordinary HTML sites, Yomu remotely checks for a repeatable catalog, a series page, chapter links and multiple reader images. It only offers Add when that complete chain is proven. Maintained Mihon/Aidoku implementations are used as evidence for future native runtimes rather than pretending a source works when it does not.
